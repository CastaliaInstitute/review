Workflow with Bibliotech

Review titles use Bibliotech for non-public EPUBs: set public_domain = false and review_section = true on the books row, store the file in Supabase Storage, then sign in to Bibliotech Readest and use Import → Import faculty review EPUBs (non-public) to load copies for annotation. Faculty highlights and notes follow the usual Readest / Supabase flow documented in the bibliotech repo. For automated chapter-by-chapter passes through ask-faculty, persisting marginalia, and generating the joint article, use the review pipeline script in Bibliotech.
